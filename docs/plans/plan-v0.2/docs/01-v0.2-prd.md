# BR AI Rules V0.2 PRD：默认资产库与项目自定义规则

## 1. 背景

V0.1 已完成最小闭环：内置 `behavior.basic` 默认规则，生成 `AGENTS.md`、`CLAUDE.md`、`.cursor/rules/ai-coding.mdc`，支持 `init / sync / diff / check / list`，并通过 managed block 保护团队自定义内容。

但 V0.1 只能安装一组通用行为规则，还不能根据不同技术栈、中间件、编码习惯安装更具体的规则资产。

V0.2 的核心是让默认资产开始分层，让用户可以通过 `--stack` 快速选择合适的规则资产，同时支持 `.ai-rules/rules/*.yaml` 项目自定义规则自动发现。

## 2. 目标用户

小团队技术负责人，团队已经在使用 Claude Code、Cursor 等 AI Coding 工具，但希望不同项目根据技术栈安装不同规范，团队自己的规则可以持续沉淀，生成文件仍然安全同步。

## 3. V0.2 目标

一句话：根据技术栈和工程习惯选择默认规范资产，并允许团队追加项目自定义规则。

核心链路：

```text
stack 输入
→ asset include
→ rule 展开
→ custom rule 自动发现
→ category 分组
→ target adapter 渲染
→ generated.json 快照
```

## 4. 非目标

V0.2 不做 Web 规则平台、远程 Hub、npm 规则包安装、规则市场、Agent 管理、Skill 执行、Hook 执行、OpenSpec 流程、Runtime 状态机、企业权限、多租户和复杂依赖冲突解决。

## 5. 默认资产分层

默认资产分为 5 层：

```text
base        通用 AI Coding 行为规则
language    编程语言规则
framework   框架规则
middleware  中间件 / 基础设施规则
practice    编码习惯 / 工程实践规则
```

## 6. 第一批内置资产

V0.2 内置 12 个资产：

```text
base.behavior-basic

```

## 7. 命令范围

保留 V0.1 命令：

```bash
br-rules init
br-rules sync
br-rules diff
br-rules check
br-rules list
```

新增：

```bash
br-rules add <rule-id>
```

增强：

```bash
br-rules init --stack react,typescript
br-rules init --stack spring-boot,java,mysql,redis
br-rules list --assets
br-rules list --custom
br-rules list --enabled
br-rules list --disabled
br-rules list --all
```

## 8. 配置文件升级

V0.2 配置建议：

```json
{
  "version": "0.2.0",
  "language": "zh-CN",
  "targets": {
    "generic": true,
    "claude": true,
    "cursor": { "enabled": true, "mode": "single" }
  },
  "assets": {
    "include": [
      "base.behavior-basic",
      "language.typescript",
      "framework.react",
      "practice.testing-basic",
      "practice.dependency-control",
      "practice.security-basic"
    ],
    "exclude": []
  },
  "disabledRules": [],
  "customRules": {
    "autoDiscover": true,
    "paths": [".ai-rules/rules/*.yaml"]
  },
  "writeMode": "managed-block"
}
```

兼容要求：如果发现旧配置 `rulesets`，应兼容读取；旧的 `behavior.basic` 映射到 `base.behavior-basic`；不要破坏 V0.1 项目。

## 9. 验收标准

1. `br-rules init --stack react,typescript` 能生成 React + TypeScript 默认资产配置。
2. `br-rules init --stack spring-boot,java,mysql,redis` 能生成后端默认资产配置。
3. `br-rules sync` 能把资产规则渲染进 `AGENTS.md`、`CLAUDE.md`、`.cursor/rules/ai-coding.mdc`。
4. 渲染结果按 category 分组。
5. `.ai-rules/rules/*.yaml` 能被自动发现。
6. `br-rules add team.xxx` 能生成自定义规则模板。
7. `br-rules check` 能检查资产、规则、重复 id、语言内容和生成文件漂移。
8. `br-rules list --assets` 能显示当前资产。
9. `br-rules list --custom` 能显示项目自定义规则。
10. `.ai-rules/generated.json` 记录资产、规则和目标文件快照。
